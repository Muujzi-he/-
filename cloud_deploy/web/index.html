使用说明：功能 · 输入输出 · 交互流程
  1. 输入：6 位沪深 ETF 代码（如 512880）必填；"计划投入金额"选填（填了会算出具体的每格金额和份数）。
  2. 输出（5 张卡片）：① 结论与 0–100 综合评分（+操作建议）；② 估值分位（PE/PB/股息率在历史中的位置）；③ 价格位置与趋势（近 3 年分位、52 周高低、均线、年化波动，附 120 日走势图）；④ 仓位与分批计划（目标仓位、首批金额、网格区间，填金额后给完整网格价格表）；⑤ 风险提示（溢价率、流动性、波动率等）。
  3. 交互流程：输入代码 → 点「诊断」→ 约 2~4 秒出结果；点上方任意快捷标签直接诊断；点自动推荐榜任意一行 → 跳回诊断页出完整方案。榜单按评分 / 估值分位 / 成交额排序，可勾选"只看低估"。
  4. 常见输入示例：510300 沪深300、512880 证券、588000 科创50、159915 创业板、513100 纳指、161005 富国天惠（场外基金）。
评分口径（多因子，满分 100）：估值分位 40% · 价格分位 25% · 质量（ROE/股息率）10% · 趋势（60/120 日双动量 + 均线排列）15% · 调整项 ±10（波动过高、流动性不足、溢价率≥5% 等扣分）。无估值覆盖的品种只按价格和趋势估算，置信度标为"中"。
仓位口径：目标仓位 = 把"计划投入金额"当作该品种上限算出的百分比；网格间距 = 近 250 日年化波动 ×1.6（限 1%~6%），建议首批 50% + 每格 10%、5 格打满。工具不预测涨跌，只给纪律化方案。

# 沪深 ETF 买入诊断器

帮助普通人判断"这只 ETF 现在能不能买、买多少"的免费本地工具。输入代码，自动给出**估值分位、价格位置、买入评分、网格分批计划、溢价率预警**，并附全市场扫描榜单。

> ⚠️ 本工具只做数据分析与纪律化仓位测算，不构成投资建议。投资有风险，入市需谨慎。

---

## 功能特性

- **单只诊断**：输入 ETF 代码，输出「值不值得买」的 0–100 评分与结论
- **全市场扫描**：自动扫描沪深股票型 ETF（约 700 只），按评分排序出"值得关注榜"和"回避榜"
- **网格分批计划**：根据当前波动率推导网格间距，给出「首批 + 分批买入」的具体金额与份数
- **溢价率检查**：区分境内 ETF（实时 IOPV）与 QDII（官方净值 + 滞后提示），高溢价自动告警
- **双端使用**：网页版（本地服务 + 可视化 K 线）或命令行快速查看
- **零依赖**：纯 Python 标准库实现，无需注册、无需 API Key

## 快速开始

需要 Python 3.8+（Windows / macOS / Linux 均可）。

### 网页版

```bash
python etf_advisor.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:8734`，可以查询单只 ETF 或一键扫描全市场。

### 命令行

```bash
python etf_advisor.py 512880                # 快速看一只，只给结论
python etf_advisor.py 512880 200000         # 结论 + 20 万资金的具体金额/份数建议
```

### Windows 一键启动

双击 `启动诊断器.bat` 即可（自动执行网页版启动命令）。

## 评判逻辑（它是怎么打分的）

评分 = **估值分位 × 0.65 + 价格分位 × 0.35 + 趋势修正**，越便宜分越高：

| 维度 | 权重 | 说明 |
|---|---|---|
| 估值分位 | 65% | PE / PB / 股息率在历史区间的位置（蛋卷基金指数估值数据） |
| 价格分位 | 35% | 现价在过去 3 年价格区间中的位置，越靠下越便宜 |
| 趋势修正 | ± | 跌破年线、距 52 周高点过近（追高）等扣分；上升趋势加分 |

结论分档：**明显低估（可积极买入）→ 偏低 → 中性（少量试探）→ 偏高 → 明显高估（回避）**。

仓位计划：先给目标仓位，再按波动率算出网格间距（近 250 日年化波动推导），建议「首批 50% + 每格 10%，5 格打满」。

## 数据来源（公开免费接口）

| 数据 | 来源 | 说明 |
|---|---|---|
| 实时行情 / 日 K | 腾讯行情（gtimg） | 主源，东方财富接口自动兜底 |
| 指数估值 | 蛋卷基金（雪球旗下） | PE/PB/股息率及历史分位，覆盖常见宽基与行业指数 |
| ETF 清单 | 新浪财经 | 全市场股票型 ETF 名单与现价 |
| 官方净值 | 天天基金 | QDII 品种溢价率计算、净值滞后提示 |

所有请求带内存缓存（TTL 10 分钟），扫描全市场约需 1–2 分钟。

## 常见问题

- **QDII 溢价率为什么标注"近似值"？** 跨境品种的官方净值会滞后 1–2 个交易日（海外市场未收盘），因此溢价是基于最新可用净值估算的，盘中可能波动。
- **为什么评分高但还在跌？** 评分是逆向的——越便宜分越高，它回答"值不值"，不回答"会不会继续跌"。深度下跌中分数依然会很高，这正是"单边下跌网格越买越套"风险的含义，务必给单个品种设总仓位上限。
- **债基 / 货币 / 黄金 ETF 适用吗？** 不适用股票式估值，工具会自动提示以价格分位和趋势为主。

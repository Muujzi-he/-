# 沪深 ETF 买入诊断器

帮助普通人判断"这只 ETF 现在能不能买、买多少"的免费本地工具。输入代码，自动给出**估值分位、价格位置、买入评分、网格分批计划、溢价率预警**，并附全市场扫描榜单。

> ⚠️ 本工具只做数据分析与纪律化仓位测算，不构成投资建议。投资有风险，入市需谨慎。

---

## 功能特性

- **单只诊断**：输入 ETF 代码，输出「值不值得买」的 0–100 评分与结论
- **全市场扫描**：自动扫描沪深股票型 ETF（约 700 只），按评分排序出"值得关注榜"和"回避榜"
- **网格分批计划**：根据当前波动率推导网格间距，给出「首批 + 分批买入」的具体金额与份数
- **溢价率检查**：区分境内 ETF（实时 IOPV）与 QDII（官方净值 + 滞后提示），高溢价自动告警
- **双端使用**：网页版（本地服务 + 可视化 K 线）或命令行快速查看
- **零依赖**：纯 Python 标准库实现，无需注册、无需 API Key

## 快速开始

需要 Python 3.8+（Windows / macOS / Linux 均可）。

### 网页版

```bash
python etf_advisor.py
```

启动后自动打开浏览器访问 `http://127.0.0.1:8734`，可以查询单只 ETF 或一键扫描全市场。

### 命令行

```bash
python etf_advisor.py 512880                # 快速看一只，只给结论
python etf_advisor.py 512880 200000         # 结论 + 20 万资金的具体金额/份数建议
```

### Windows 一键启动

要用时双击 `启动诊断器.bat`，浏览器自动打开 `http://127.0.0.1:8734`；关掉黑窗口就是停止服务。重复双击不会报错——检测到端口已有服务时，它直接打开页面。

### 手机/平板访问（同一 WiFi）

电脑执行 `python etf_advisor.py --lan`，会打印出本机局域网地址（形如 `http://192.168.x.x:8734`），手机连**同一个 WiFi**打开它即可。注意两点：`127.0.0.1` 在手机上指的是手机自己，永远打不开电脑上的服务；校园网/公司网通常有设备隔离并且把网络判为「公用」，Windows 防火墙默认拦入站，这种情况下要么换成手机热点，要么用下面的公网隧道。

### 手机随时随地访问（公网隧道，免公网 IP/免备案）

双击 `启动公网隧道.bat`：它会自动拉起诊断服务、下载并启动 Cloudflare Tunnel（免费、无需注册），窗口里会打印一个 `https://xxxx.trycloudflare.com` 的 HTTPS 地址——**手机用流量、在地球任何角落都能打开**，数据仍然从你家电脑出。

三个诚实的限制：
- 免费临时隧道的地址**每次启动随机变化**，换地址了就重新看一眼窗口；
- 电脑关机/断网，公网地址就失效——它本质上还是"把家里电脑变成服务器"；
- 这个地址谁拿到都能看（工具本身只读、无敏感数据），介意的话只自己用、用完关窗口。

想要固定域名：注册 Cloudflare（免费）绑定一个自己的域名建命名隧道，或花几十块买台云服务器部署，思路相同——把 8734 端口的服务暴露出去即可。

### 开机自启（可选，默认不开）

`127.0.0.1:8734` 是本机进程临时开的服务，**进程没在跑就打不开网页**（浏览器会报 `ERR_CONNECTION_REFUSED`）。如果你不想每次双击，可以装登录自启（后台静默，不弹窗口）：

```bash
python etf_advisor.py --install     # 安装：在当前用户的「启动」文件夹放一个静默启动快捷方式
python etf_advisor.py --status      # 查看：是否已安装、本机端口有没有服务在跑
python etf_advisor.py --uninstall   # 卸载：删除该快捷方式
```

自启用的是 `pythonw.exe etf_advisor.py --silent`。**当前状态：未安装**，按需双击 bat 即可。

## 评判逻辑（它是怎么打分的）

多因子评分，越便宜、趋势越顺、质量越高，分数越高：

| 维度 | 权重 | 说明 |
|---|---|---|
| 估值分位 | 40% | PE / PB / 股息率在历史区间的位置（蛋卷基金指数估值数据） |
| 价格分位 | 25% | 现价在过去 3 年价格区间中的位置，越靠下越便宜 |
| 质量 | 10% | ROE、股息率加分 |
| 趋势 | 15% | 60/120 日双动量 + MA20/60/120 均线多头排列 |
| 调整项 | ±10 | 波动率过高、流动性不足、溢价率 ≥5% 等扣分封顶 |

结论分档：**明显低估（可积极买入）→ 偏低 → 中性（少量试探）→ 偏高 → 明显高估（回避）**。

每次打分都会输出每条加减分的中文理由（例如"ROE 31.6%，质量加分""均线空头排列，趋势修正 -7"），保证可解释。

仓位计划：先给目标仓位，再按波动率算出网格间距（近 250 日年化波动推导），建议「首批 50% + 每格 10%，5 格打满」。

所有请求带内存缓存（TTL 10 分钟），扫描全市场约需 1–2 分钟。

## 常见问题

- **QDII 溢价率为什么标注"近似值"？** 跨境品种的官方净值会滞后 1–2 个交易日（海外市场未收盘），因此溢价是基于最新可用净值估算的，盘中可能波动。
- **为什么评分高但还在跌？** 评分是逆向的——越便宜分越高，它回答"值不值"，不回答"会不会继续跌"。深度下跌中分数依然会很高，这正是"单边下跌网格越买越套"风险的含义，务必给单个品种设总仓位上限。
- **债基 / 货币 / 黄金 ETF 适用吗？** 不适用股票式估值，工具会自动提示以价格分位和趋势为主。
